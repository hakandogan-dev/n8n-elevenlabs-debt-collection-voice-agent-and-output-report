## Upload in the browser

1. Create a new, empty repository in your GitHub account. Choose Public if you intend to share it openly.
2. Extract the ZIP and open the project directory.
3. Upload the contents of that directory, preserving the `assets`, `docs`, `examples`, `scripts`, `tests` and `workflows` folders. `README.md` should sit at the repository root.
4. Add the description and topics above. GitHub will render the README and its relative images automatically.

The package intentionally contains no open-source license. Keep that choice unless you decide to grant reuse rights.

## Upload with Git

From the extracted project directory, using your own Git identity and the URL of your new repository:

```bash
git init -b main
git add .
git commit -m "Add public voice-agent architecture portfolio and n8n scaffolds"
git remote add origin YOUR_NEW_REPOSITORY_URL
git push -u origin main
```

Only the public project directory belongs in this repository. The original uploaded configuration and workflow exports are not part of the package. The supplied workflow screenshot is included in `assets/elevenlabs-workflow.png`.
